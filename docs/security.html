Security

Read this before you point it at a site

a11ign drives a real browser and a real screen reader on a page you name. It doesn’t just look. It operates controls the way a user would, so know what it touches.

What it does to a page

ActionWhen
Opens disclosures, such as menus and drop-downsAlways. Opening something has no side effects.
Follows the first link on the pageBy default. It’s usually the skip link. Turn it off with --no-probe-navigation.
Submits forms and presses buttonsOnly if you turn on probe-forms. It’s off by default.
Ticks checkboxes and radio buttonsOnly with probe-forms on.
Types values you wrote into fieldsOnly if you give it a forms file.

Stay safe

  • Run it on a staging app with test data, not on production.
  • If you turn on probe-forms on a page you don’t own, you’re operating someone else's application.
  • Never put real passwords or personal data in a forms file. It’s read as written, typed into a live page, and can appear in the transcript.

What it sends

Nothing. It talks to the page you point it at and to your own machine. There’s no tracking and no phoning home.

Report a problem privately

If you find a security problem, use GitHub's private vulnerability reporting. Please don’t open a public issue for anything that could be abused. This is a small project, so we promise no response time, but we’ll read every report.
