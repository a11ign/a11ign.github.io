How we know it works

The short answer

We didn’t start on the real web. We taught and tested a11ign in steps: first on pages we built ourselves, where we know exactly what is right and wrong, then on a test set it had never seen, then on real websites. Here’s each step, with the numbers.

Step 1: learning from pairs of pages

We built about 1,250 page patterns. Each one exists in two versions: one accessible, one deliberately broken. Real NVDA read every version on our own Windows machines, and we recorded exactly what it said.

WhatHow many
Page captures4,668
Accessible versions2,335
Broken versions2,333
Page patterns they are built fromAbout 1,250
Older and rejected captures we keep, to learn from what went wrongAbout 2,800

Because every page comes as a matching pair, a11ign learns what changes in what NVDA says when one thing is broken. That’s the heart of how it learned.

Step 2: a test set it never saw

We held back 231 pages and captured each one twice, about 990 captures in all. They were never used for training. They exist only to check the result.

Pages we build ourselves only go so far, so the next step is real websites.

Step 3: real websites

Real pages are the measurement that matters most. We have 129 so far.

  • Across 1,405 records of pages that meet the standard, the exact rules raised no false alarms. That’s our own test set.
  • On 40 real pages that meet the standard (measured 24 September 2026), no rule failed a page wrongly, and 395 findings were passed to a person to judge.

How we test the code

CheckWhat it covers
About 1,900 unit testsThe exact rules, the judge, the report and the evaluation code. They run on every change.
34 labelled pagesW3C tutorial pages and paired good and bad examples, used to check the judge.
A false-alarm checkThe exact rules must raise no false alarm on a page that meets the standard. One miss fails the check.
A real NVDA capture checkReal NVDA, on a GitHub-hosted Windows machine, to check the capture part still works.

The quick check

The quick check predicts what NVDA would say, without a screen reader. We set the pass mark at 98% in advance. On a new set of pages it was not tuned to, it agreed with real NVDA on the 10 most common kinds of announcement 99.71% of the time (3,497 of 3,507), and we named every miss.

These are measurements on our own test sets, as of 17 October 2026.

What’s next

a11ign is live and working today. It’s a new kind of tool, and we’re only getting started.

  • Accessibility specialists labelling real pages, so we can check our calls against theirs.
  • More screen readers, starting with JAWS and VoiceOver.
  • Multi-step flows, like signing in and checking out.
  • The quick check, running inside the Playwright tests you already have.
