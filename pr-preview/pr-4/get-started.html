Add a11ign to your workflow

Option 1: GitHub Action

Recommended

You don’t need a Windows machine. GitHub provides one.

.github/workflows/a11ign.yml
jobs:
  a11y:
    runs-on: windows-2022
    steps:
      - uses: actions/checkout@v7
      - uses: a11ign/a11ign@<release-commit>
        with:
          url: https://example.com/contact
          task: Send an enquiry
  1. 1Save it as .github/workflows/a11ign.yml
  2. 2Open a pull request
  3. 3Read the report in the comment

Prompt for your AI agent
Add a11ign to this repository as a GitHub Action.

a11ign runs the NVDA screen reader over web pages and reports accessibility barriers, quoting what NVDA said. It needs a Windows runner, which GitHub provides.

If I have not told you, ask me for (a) the page URL to test and (b) one sentence on what a user does there, for example "Send an enquiry".

1. Find the latest release: run git ls-remote https://github.com/a11ign/a11ign "refs/tags/a11ign@*". Use that release’s full 40-character commit SHA (not a tag or branch) and note the release name in a comment.
2. Create .github/workflows/a11ign.yml. Trigger on pull_request and workflow_dispatch. Use runs-on: windows-2022, timeout-minutes: 20, and permissions contents: read and pull-requests: write.
3. Steps: actions/checkout; then a11ign/a11ign at that SHA with id: a11ign, url and task set from my answers; then actions/upload-artifact with if: always() to keep the result-json and summary-md outputs.
4. Leave fail-on at its default so findings cannot fail the build. Do not turn on probe-forms.
5. Add no API keys or secrets. None are needed.
6. Open a pull request with the change and tell me what to expect: the report appears as a comment on the pull request, and the result files are saved with the run.

Do not say the site is accessible or compliant. The report lists findings for a person to check.

Check the version it pins. It should be a full 40-character commit from an a11ign@ release.

Option 2: Command line

Run it from your own machine. a11ign needs a Windows machine with NVDA to drive.

  1. 1Set up a Windows machine with NVDA

Already have one? Run this in an elevated PowerShell on it. It installs Node, Git and NVDA, starts the worker, then restarts the machine. That restart is expected.

PowerShell, on the Windows machine
Set-ExecutionPolicy -Scope Process Bypass -Force
irm https://raw.githubusercontent.com/a11ign/screenreader-fleet/main/packages/worker-fleet/src/provisioning/bootstrap-windows-worker.ps1 | iex

No Windows machine? On a Mac you can build a Windows virtual machine with the scripts in a11ign/screenreader-fleet. Most of the wait is downloading Windows.

  1. 2Tell a11ign where it is
Your own machine
export A11Y_WORKER=http://<that-machine>:8765
curl $A11Y_WORKER/health
  1. 3Run it
Command line
npx a11ign https://example.com --task "Find the contact details"

Something not working? Run pnpm run doctor in a11ign/control. It checks each step and prints the fix.

What you need

For the GitHub Action

  • A GitHub project

For the command line

  • Node.js 20 or newer
  • A Windows machine with NVDA, set up with one command (step 1)
