Test accessibility the way a screen reader user hears it.

a11ign runs a real screen reader (NVDA) over your pages and shows you the barriers it hits, with the exact words it said.

What a11ign does

A real screen reader, not a guess.

a11ign runs NVDA, a free Windows screen reader, over your page and records what it says.

Every finding shows its proof.

Each finding names the WCAG 2.2 rule it breaks and quotes what the screen reader said, so you can check it yourself.

Findings land in your pull request.

The report appears as a comment on your pull request, so you see problems where you already review code.

01

How it works

  1. 1Add a few lines to your GitHub project.
  2. 2GitHub runs a11ign on a Windows machine, with a real screen reader.
  3. 3Read the report on your pull request.
.github/workflows/a11ign.yml
jobs:
  a11y:
    runs-on: windows-2022
    steps:
      - uses: actions/checkout@v7
      - uses: a11ign/a11ign@<release-commit>
        with:
          url: https://example.com/contact
          task: Send an enquiry

What a report looks like

04

Two ways to check

Available now

Real NVDA, before you release

Drives real NVDA over your pages and quotes what it said, as a comment on your pull request. Run it before a release and on the flows that matter. The proof is the words NVDA said.

Coming soon

A quick check in the tests you already run

Predicts what NVDA would say without a screen reader, on any operating system, so it can run on every commit. It’s always labelled a prediction, never proof. A real NVDA run confirms it.

Star the project to follow it
05

What to expect

  • Proof, not a score: every finding quotes what the screen reader said.
  • Evidence you can act on, alongside your own judgement and legal advice.
  • Focused on the pages you choose, like checkout, sign-up and search.
  • Some findings say “worth a look”, because a person makes the final call.
  • No Windows machine needed: GitHub provides one when you use the Action.

What we’ve measured: across 1,405 records of pages that meet the standard, the exact rules raised no false alarms. That’s our own test set, so treat it as a starting point. How we know it works
