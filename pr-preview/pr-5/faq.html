Questions before you try it

Getting started

Do I need a Windows machine?
Not if you use the GitHub Action. GitHub provides the Windows machine. Running it yourself needs one, because NVDA only runs on Windows.
Do I need an account or an API key?
No. The default judge ships with a11ign, and your page isn’t sent anywhere.
Will it break my build?
No. By default, findings don’t fail your build (fail-on is set to never), so it’s safe to add.
How long does a run take, and what does it cost?
A single page takes roughly two to eight minutes of machine time, depending on the page. In a private repository, GitHub charges more per minute for Windows runners than for Linux ones, so we suggest running a11ign on key flows and before releases, not on every commit.
Can it reach my staging site?
The runner has to be able to open the page. A public staging URL works. For an app that only runs inside your network, start it in an earlier step of the workflow, or use a self-hosted runner.
Can I use my own runner?
Yes, you swap the runs-on line for your own Windows runner labels. The machine needs an interactive desktop session, because NVDA needs one. Try it on a test pipeline first.

What it finds

How does it move through a page?
Not just with the Tab key. It navigates the way screen reader users do: by headings, landmarks, form fields, images, links and lists. Then it operates the controls it finds, because some problems only show up after something is activated.
Does it give a score?
No, on purpose. One number hides what wasn’t checked. You get a clear result for each rule instead: failed, passed, not applicable, can’t tell, or not tested.
Which standards does it report against?
WCAG 2.2 AA, and WCAG 2.1 AA too, since that’s the version many laws point to. Every result lists what was checked and what wasn’t, so nothing is quietly skipped.
Does it work with axe-core?
Yes. Run both. a11ign goes deep on the rules that need a screen reader, and axe-core covers many more quickly, including colour contrast. You can also feed in the axe-core results you already have.
Why are most findings marked referred?
Referred means worth a look. Some things, like whether a link called Learn more is clear enough, depend on context a person has to judge. a11ign quotes what was said and points you to the spot.
What if it can’t read a page?
It tells you. A page it couldn’t measure is never reported as clean, and the run exits with an error whatever your fail-on setting says.
Does it replace manual testing?
No. Think of it as triage. It finds the moments worth a person’s attention and hands you the exact words the screen reader said, so nobody has to hunt for where to look.
Can it check PDFs?
Yes. Point it at a PDF link and it reads the document’s tag structure, with no screen reader needed. It flags untagged documents, a missing language, and images with no alternative text.
Is the quick check the same as a real screen reader?
No. It predicts what NVDA would say, and we publish how often it agrees. A real NVDA run confirms it. It’s coming soon.

How it works

Which screen reader and browser does it use?
NVDA, a free Windows screen reader, with Microsoft Edge. The NVDA version is recorded in every result, so you can see exactly what ran. JAWS, VoiceOver and Orca are planned.
Does it work on single-page apps?
Yes. It drives a real browser, so client-rendered pages load as they do for your users. It also checks route changes, such as a page that updates without its title changing.
Can it test pages behind a login?
Yes, for a username and password form, including one-time codes from an authenticator app. Single sign-on, push or text-message codes, security keys and captchas aren’t supported. The repository has to be private for logged-in runs.
Can I test more than one page?
Yes. List the pages in the urls setting, one per line. It’s a list you write, not a crawl. Lists longer than 5 need max-pages, up to 25.
What does the task setting do?
It labels the run, and it names a button for the optional form check. It doesn’t change the analysis.
Will I get the same result every time?
It’s built to be repeatable, with a pinned setup and the versions recorded in each result. Live pages change though, so results can change when your page does.
Does it need a sound device?
No. a11ign reads NVDA’s speech as text, not audio, so the machine doesn’t need speakers or a sound card.
Does it use AI, and can I swap the model?
By default it uses a11ign’s own trained model, which runs on the runner. You can swap in another judge, such as an OpenAI-compatible or Anthropic model, or a local one. Those need your own key or endpoint, and they send the transcript to that provider.

Safety and privacy

Do we process your data?
No. It only talks to the page you point it at and your own machine. No tracking, no phoning home.
What does it press on my site?
It operates controls the way a screen reader user would, and one optional setting presses buttons. Read the security page and try it on a staging app first.

Licence and law

Can I run it in CI on my own app?
Yes. The licence gives you unlimited permission to run the unmodified program. This isn’t legal advice, so check with your own counsel.
Can I use it in a closed-source project?
Running it is fine. If you modify a11ign and run it as a service, the licence says you share your changes. If that doesn’t suit you, a commercial licence may come later. Open an issue to talk about it.
Can it help us show we meet a legal requirement?
It gives you evidence to support that work. Whether your site meets a requirement is for you and your counsel to decide.
