What a11ign checks, and how it fits your tech stack

What a screen reader catches that code checks miss

  • A skip link that does nothing

    It looks right in the code, but pressing it goes nowhere. Code checks pass while a screen reader user is stuck.

  • A page change nobody hears

    The page updates but the title doesn’t, so nobody is told where they are now.

  • A filter or form that says nothing

    Results change or an error appears, and nothing is read out.

  • Tab order that fights reading order

    The order you tab through the page and the order it’s read out disagree, and only a real walkthrough shows it.

How a finding is decided

Asserted: the evidence settles it, so the report says the rule isn’t met. Referred: the evidence points to a problem but a person should decide, so the report quotes the words and points you to them.

What we’ve measured: across 1,405 records of pages that meet the standard, the exact rules raised no false alarms. That’s our own test set. Most findings are marked referred, and that’s expected.

Fits inside your tech stack

a11ign adds to the tools you already use. It doesn’t replace them.

  • GitHub Actions

    One step in your workflow, on a Windows runner GitHub provides. The report appears as a pull request comment, and the results are saved with the run.

  • axe-core

    Run it next to axe-core, or feed in the axe-core results you already have, so you still have one engine and one version.

  • Command line

    Run it with npx from your own Windows machine with NVDA, when you want it outside CI.

  • Playwright tests

    Coming soon: the quick check predicts what NVDA would say inside the Playwright tests you already run.

What to expect

  • Proof, not a score: every finding quotes what the screen reader said.
  • Evidence you can act on, alongside your own judgement and legal advice.
  • Focused on the pages you choose, like checkout, sign-up and search.
  • Built to sit beside your other checks. Run it with axe-core, which covers colour contrast.
  • One screen reader, done properly: NVDA today. Braille, magnification and voice control aren’t covered yet.
