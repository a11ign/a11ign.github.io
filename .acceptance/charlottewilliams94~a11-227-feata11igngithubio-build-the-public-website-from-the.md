The a11ign website replaces the Astro starter's "Hello, world" page: 16 content pages and a 404 built from the approved design canvas, with the copy carried over as written, in both themes at desktop and phone widths, with no JavaScript framework, no analytics, no cookie and self-hosted fonts. `npm run check` builds the site, checks the built files (no Google Fonts, no `document.cookie`, sitemap, robots.txt and llms.txt, a preview build under `/pr-preview/pr-1/`), then runs Playwright with axe-core against WCAG 2.2 AA on all 17 pages at 390 and 1440 in light and dark (68 views), plus the keyboard, theme, Copy, filter, tab, menu, SEO and JSON-LD behaviour checks.

Acceptance: bash -c 'set -euo pipefail; npm ci; npx playwright install chromium; npm run check; grep -rE "fonts\.(googleapis|gstatic)\.com|document\.cookie" dist && exit 1; diff dist/robots.txt src/data/seo/robots.txt; diff dist/llms.txt src/data/seo/llms.txt; echo PASS'
